 VR クロマキーパネル  v1.0.0
 作者: ゆるる (https://x.com/yururutti)
 ソース: ★https://github.com/Yurutama/VR-Chroma-key-panel★
========================================================

VR空間に「緑の板」を置いて、Virtual Desktop のクロマキー
パススルーで、現実のキーボードや机を映すためのツールです。

板の位置・角度・大きさをコントローラーでつかんで調整でき、
その設定はそのまま保存されます。


--------------------------------------------------------
 0. まず確認してください（重要）
--------------------------------------------------------
このツールが役に立つのは、次の環境の人だけです。

  ・Windows PC + SteamVR
  ・Virtual Desktop の「クロマキーパススルー」を使っている

Quest Link / Air Link にはクロマキー機能がありません。
その場合、緑の板が浮かぶだけで現実は映りません。

このツールは VRChat のファイルを一切改変しません。
SteamVR のオーバーレイ機能だけを使っています。


--------------------------------------------------------
 1. 2つの版があります
--------------------------------------------------------
■ exe版（おすすめ・初めての方はこちら）
   Python は不要です。解凍してそのまま起動できます。

■ Python版（中身を見たい・自分で改造したい方向け）
   下記の GitHub で配布しています。
     ★https://github.com/Yurutama/VR-Chroma-key-panel★
   Python 3.9 以降が必要です。
   インストール時に「Add python.exe to PATH」への
   チェックが必須です。

どちらも機能はまったく同じです。


--------------------------------------------------------
 2. 使い方（exe版）
--------------------------------------------------------
1) zip を「解凍してから」使ってください。
   zip の中身を直接ダブルクリックしても動きません。
2) フォルダの中身は 1 つも消さないでください。
   exe 単体を取り出すと起動しません。
3) SteamVR を起動します。
4) VRChromaPanel.exe をダブルクリックします。
5) 初回だけ「WindowsによってPCが保護されました」と
   青い画面が出ます。「詳細情報」→「実行」で起動できます。
   （詳しくは 5章のQ&Aを見てください）
6) 操作ウィンドウが開いたら、VR側に緑の板が出ます。


--------------------------------------------------------
 3. 使い方（Python版）
--------------------------------------------------------
1) zip を解凍します。
2) SteamVR を起動します。
3) run.bat をダブルクリックします。
4) 初回だけ、必要な Python パッケージのインストール確認が
   出ます。y を入力して Enter を押してください。
   （入るのは openvr と pillow の2つだけです）
5) 操作ウィンドウが開いたら、VR側に緑の板が出ます。


--------------------------------------------------------
 4. 操作方法
--------------------------------------------------------
■ 板を動かす
   板にコントローラーを近づけて（30cm以内）、
   トリガーまたはグリップを握るとつかんで動かせます。

■ 位置を見失ったとき
   「目の前に配置」ボタンで、視界の正面に戻せます。

■ モード
   空間固定 (Standing)
     通常はこれ。床の高さが基準になります。
   空間固定 (Raw)
     リセンターしても板がズレません。
     OVR Advanced Settings などで空間移動する人向け。
   頭に追従
     常に視界の同じ位置に出ます。

■ 保存
   「保存」を押すと chroma_panels.json が作られます。
   次回からその位置で起動します。
   このファイルは exe（または run.bat）と同じフォルダに
   できます。

 5. よくある質問
--------------------------------------------------------
Q.「WindowsによってPCが保護されました」と出て起動できない
A. 作者が有料の署名証明書を持っていないため、Windows が
   「よく知らないアプリ」として警告を出しています。
   青い画面の「詳細情報」をクリックし、下に出てくる
   「実行」を押せば起動できます。
   一度実行すれば、次からは出ません。

Q. ウイルス対策ソフトに削除された・警告が出た
A. exe版でよく起きる誤検知です。中身は Python のスクリプト
   をそのまま固めたもので、悪いことは何もしていません。
   気になる場合は、GitHub で公開しているソースを読める
   Python版をお使いください。
   使い続ける場合は、フォルダを除外設定に追加してください。

Q.「起動できません」と出る
A. SteamVR が起動していません。先に SteamVR を立ち上げて
   から、もう一度実行してください。

Q. run.bat を開いても一瞬で消える（Python版）
A. Python が入っていない可能性が高いです。画面に出た説明の
   とおりに Python を入れ直してください。
   Microsoft Store の画面が開く場合は、Windows の設定
   「アプリ実行エイリアス」で python を OFF にしてください。

Q. 板が見えない
A. ・「表示」のチェックが外れていないか
   ・板が体の中や床下に埋まっていないか
     →「目の前に配置」ボタンで戻せます
   ・他のオーバーレイ(XSOverlay等)の裏に隠れていないか
   ※ クロマキーの設定が済んでいる場合、板は「透けて現実が
     映る」のが正常です。緑の板が見えなくなったら成功です。

Q. 現実が映らず、緑一色になる
A. Virtual Desktop 側のクロマキー設定を確認してください。
   板の色と、クロマキーで抜く色を揃える必要があります。

   Virtual Desktop（VR内のメニュー）の STREAMING の下の方に
   ある VR Passthrough の Environment にチェックを入れ、
   右の Configure をクリックして、次のように設定します。

     Green だけ 255（Red と Blue は 0）
     Similarity        : 2 %
     Smoothness        : 20 %
     Passthrough opacity : 100 %

   ※ 板の色が #00FF00（初期設定）の場合の数値です。
     色を変えた場合や、映りがおかしい場合は、自分で
     ちょうど良い数値に調整してください。

Q. リセンターすると（OVRで移動すると）板がズレる
A. モードを「空間固定 (Raw)」にしてください。

Q. 設定した位置が次回に引き継がれない
A.「保存」を押したか確認してください。また、Program Files
   などの書き込みできない場所に置くと保存に失敗します。
   デスクトップやドキュメントの下に置いてください。

Q. アンインストールしたい
A. フォルダごと削除すれば終わりです。レジストリなどは
   一切いじっていません。Python版で入れたパッケージを
   消す場合は  python -m pip uninstall openvr pillow
